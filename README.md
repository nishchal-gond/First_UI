# First UI

A [Frontend Mentor](https://www.frontendmentor.io/) challenge build — the
**Article preview component**: a responsive article card with an author footer and
a share button that reveals a tooltip.

Built with HTML, CSS and vanilla JavaScript. No framework, no build step.

![Design preview](./First%20Ui%20Challange/design/desktop-preview.jpg)

## Running it

Open `First Ui Challange/index.html` in a browser.

## What the challenge involves

- Matching the supplied desktop and mobile designs
- A share button that toggles a tooltip, with different placement per breakpoint —
  the tooltip floats above the button on desktop and replaces the author footer on
  mobile
- Hover and active states from the provided state designs

## Layout

```
First Ui Challange/

```

`README-template.md` is the unfilled scaffold Frontend Mentor ships with each
challenge; `First Ui Challange/README.md` is the filled-in write-up.
